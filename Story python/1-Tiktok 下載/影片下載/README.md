# TikTok 影片下載器 使用說明

## 📋 功能特色

✅ 下載無浮水印的 TikTok 影片
✅ 支援單個或批次下載多個影片
✅ 自動命名影片檔案（使用影片標題）
✅ 顯示下載進度
✅ 圖形化介面，操作簡單

## 🔧 安裝步驟

### 1. 確保已安裝 Python
需要 Python 3.7 或更高版本

### 2. 安裝必要套件
在命令提示字元或終端機中執行：
```bash
pip install -r requirements.txt
```

或直接安裝：
```bash
pip install requests
```

## 🚀 使用方法

### 執行程式
```bash
python tiktok_downloader.py
```

### 操作步驟

1. **選擇儲存位置**
   - 程式啟動後會彈出資料夾選擇對話框
   - 選擇你想要儲存影片的資料夾

2. **選擇下載模式**
   - **單一影片**: 只下載一個影片
   - **批次下載**: 可以連續輸入多個連結下載多個影片

3. **貼上 TikTok 連結**
   - 在對話框中貼上 TikTok 影片連結
   - 支援的連結格式：
     - `https://www.tiktok.com/@username/video/1234567890`
     - `https://vm.tiktok.com/xxxxxx/`
     - `https://vt.tiktok.com/xxxxxx/`

4. **等待下載完成**
   - 程式會顯示下載進度
   - 完成後會顯示結果統計

## 📝 支援的連結格式

```
✓ https://www.tiktok.com/@username/video/1234567890
✓ https://vm.tiktok.com/ZSexample/
✓ https://vt.tiktok.com/ZSexample/
✓ 短連結會自動解析
```

## ⚠️ 注意事項

1. **網路連接**: 需要穩定的網路連接才能下載
2. **連結有效性**: 請確保連結指向公開的影片
3. **私人帳號**: 無法下載私人帳號的影片
4. **地區限制**: 某些地區限制的影片可能無法下載
5. **版權問題**: 請尊重創作者的版權，僅供個人學習使用

## 🐛 常見問題

### Q: 下載失敗怎麼辦？
A: 
- 檢查網路連接是否正常
- 確認 TikTok 連結是否正確
- 嘗試使用其他連結格式
- 確認影片是否為公開影片

### Q: 影片下載很慢？
A: 
- 取決於你的網路速度和影片大小
- 可以嘗試在網路較好的環境下載

### Q: 無法獲取影片資訊？
A: 
- API 服務可能暫時無法使用
- 嘗試稍後再試
- 確認連結是否為有效的 TikTok 影片連結

### Q: 檔案名稱出現亂碼？
A: 
- 程式會自動清理非法字元
- 如果標題過長，會自動截斷至 50 字元
- 重複檔名會自動添加數字後綴

## 💡 使用技巧

1. **批次下載**: 如果要下載多個影片，建議選擇批次模式
2. **整理影片**: 可以為不同類型的影片創建不同的資料夾
3. **命名規則**: 影片會自動使用原始標題命名，方便識別
