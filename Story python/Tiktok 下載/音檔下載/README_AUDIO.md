# TikTok 音檔下載器 使用說明

## 📋 功能特色

✅ 下載 TikTok 影片的背景音樂/音檔
✅ 支援單個或批次下載多個音檔
✅ 自動命名音檔（作者 - 歌曲名稱）
✅ MP3 格式，相容性高
✅ 顯示下載進度和檔案大小
✅ 圖形化介面，操作簡單

## 🔧 安裝步驟

### 1. 確保已安裝 Python
需要 Python 3.7 或更高版本

### 2. 安裝必要套件
在命令提示字元或終端機中執行：
```bash
pip install requests
```

## 🚀 使用方法

### 執行程式
```bash
python tiktok_audio_downloader.py
```

### 操作步驟

1. **選擇儲存位置**
   - 程式啟動後會彈出資料夾選擇對話框
   - 選擇你想要儲存音檔的資料夾

2. **選擇下載模式**
   - **單一音檔**: 只下載一個音檔
   - **批次下載**: 可以連續輸入多個連結下載多個音檔

3. **貼上 TikTok 連結**
   - 在對話框中貼上 TikTok 影片連結
   - 程式會自動提取該影片的背景音樂
   - 支援的連結格式：
     - `https://www.tiktok.com/@username/video/1234567890`
     - `https://vm.tiktok.com/xxxxxx/`
     - `https://vt.tiktok.com/xxxxxx/`

4. **等待下載完成**
   - 程式會顯示下載進度和檔案大小
   - 完成後會顯示結果統計

## 📝 音檔命名規則

音檔會自動命名為：
```
作者名稱 - 歌曲名稱.mp3
```

例如：
- `Taylor Swift - Anti-Hero.mp3`
- `Unknown Artist - Original Sound.mp3`

## 🎵 音檔格式

- **格式**: MP3
- **來源**: TikTok 影片的背景音樂
- **品質**: 原始音質（由 TikTok 提供）

## ⚠️ 注意事項

1. **網路連接**: 需要穩定的網路連接才能下載
2. **連結有效性**: 請確保連結指向公開的影片
3. **音樂版權**: 
   - 僅下載背景音樂/原聲
   - 請尊重音樂創作者的版權
   - 僅供個人欣賞和學習使用
4. **私人帳號**: 無法下載私人帳號影片的音檔
5. **原創音檔**: 如果影片使用的是原創音檔，檔名可能會顯示為 "Original Sound"

## 🐛 常見問題

### Q: 下載失敗怎麼辦？
A: 
- 檢查網路連接是否正常
- 確認 TikTok 連結是否正確
- 確認影片是否為公開影片
- 某些影片可能沒有可提取的音檔

### Q: 音檔品質如何？
A: 
- 音檔品質取決於 TikTok 原始音質
- 通常為標準 MP3 品質
- 適合一般聆聽和使用

### Q: 可以下載原創音檔嗎？
A: 
- 可以，程式會自動提取影片的背景音樂
- 無論是流行歌曲還是原創音檔都可以下載

### Q: 為什麼檔名顯示 "unknown"？
A: 
- 某些影片的音樂資訊可能不完整
- 程式會使用預設名稱 "unknown"
- 可以手動重新命名檔案

### Q: 可以批次下載多個音檔嗎？
A: 
- 可以！選擇批次下載模式
- 連續輸入多個 TikTok 連結
- 程式會自動依序下載
